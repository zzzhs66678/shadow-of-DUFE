小影路径不提供站点地图入口，并返回 `X-Robots-Tag: noindex, nofollow, noarchive`。隐藏路径不作为安全边界，服务端仍校验邀请码、会话、请求来源和速率。

## 同域 API

| 路径 | 用途 | 主要保护 |
| --- | --- | --- |
| `/api/auth/session` | 读取登录状态 | Secure、HttpOnly 会话 Cookie，服务端会话校验 |
| `/api/auth/login/*` | OAuth 登录事务 | 一次性 state、浏览器绑定、10 分钟有效期、限流 |
| `/api/auth/devices` | 设备列表和撤销 | 登录、同源写校验、限流 |
| `/api/auth/personal` | 个人课表、日程和作业同步 | 登录、同源写校验、12KB 请求上限、版本冲突与幂等键 |
| `/api/auth/account/delete` | 账号注销 | 登录、同源写校验、确认短语 |
| `/campus-lab/v1/*` | 小影授权、预约、提醒、同步与数据删除 | 独立 Cookie 路径、SameSite=Strict、同源写校验、限流、加密凭据 |

PostgreSQL、SQLite 与服务容器端口只在 Docker 私有网络暴露，不映射公网端口。

## Cookie 与浏览器存储

| 名称 | 范围 | 内容 | 有效期 |
| --- | --- | --- | --- |
| `__Host-dufesh_session` | 全站 | 32 字节随机会话令牌；数据库只保存带服务端 pepper 的摘要 | 最长 30 天 |
| `__Secure-dufesh_xiaoying_session` | `/campus-lab` | 小影随机会话令牌；数据库只保存摘要 | 最长 30 天 |
| OAuth 临时 Cookie | OAuth 回调 | 浏览器绑定随机值 | 最长 10 分钟 |
| `dufesh:student-profile:v2` | 当前浏览器 | 未登录用户的专业、课表、日程、作业和偏好 | 用户清理或主动删除前 |
| 个人同步元数据 | 当前浏览器 | 同步版本、时间和冲突提示 | 用户退出或清理前 |

正式 Cookie 不设置 `Domain`，使用 `Secure`、`HttpOnly` 和明确的 `SameSite`。小影 Cookie 只随 `/campus-lab` 请求发送。

## 结构化数据与保存

- PostgreSQL 保存主站用户、身份、设备、会话、课表、日程、作业和同步版本。
- 小影当前使用独立 SQLite 数据卷，保存 VIP 昵称、偏好、提醒规则、加密第三方凭据和加密模型密钥。
- OAuth 过期事务保留 1 天，过期主站会话和同步请求记录保留 30 天，软删除记录和撤销设备最多保留 180 天。
- 小影会话最长 30 天。用户断开白果云、图书馆或模型服务时，相关密文立即删除；删除小影账号会级联清理该用户的全部小影数据。
- Docker 日志按文件大小轮转；日志不记录 Cookie、授权链接、API 密钥或学校账号密码。
- PostgreSQL 每日压缩备份，本地只保留最近一份已验证备份。OSS 未开通前不宣称异地备份。
