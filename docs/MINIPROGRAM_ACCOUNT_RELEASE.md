# 原生小程序账号接入

候选基于2026-10-12实际线上网站b36b1cf和账号服务ba59dfe的共同源码；仍为32项迁移，未新增数据库结构。只扩展账号服务，网站页面及其他服务保持。

新增 `/api/auth/miniprogram/login`、`session`、`logout`、`snapshot`。使用网站现有账号密码，不创建另一套用户；原生会话HMAC加入独立用途前缀，网页Cookie和原生Bearer双向不能替代。会话最长24小时，沿用现有改密、停用和撤销机制、Argon2id、网络/账号限额及登录失败锁定。原生路由拒绝浏览器Origin、查询参数、Cookie认证和私人快照写入；原网页登录与Origin检查未放宽。读取快照后重新确认原会话有效，再返回完整revision/state，不修改原课表。

`AUTH_MINIPROGRAM_ENABLED`默认false；完成候选检查及客户端合法域名后显式开启。没有微信登录、注册、社区写入或自动合并本机数据；小程序凭据不进入URL或日志。生产部署应仅替换auth-api，保留现有app/current、32次迁移和配置中的其他值；记录单独的auth版本，不能把auth候选当成网站页面已升级。

验证包括5项真实HTTP边界测试、已有账号服务167项回归、真实数据库集成的3项子流程；原生PG集成已加入既有quality工作流。正式部署、CI与手机验收结果必须追加实际证据，不把本地测试写成已上线。
