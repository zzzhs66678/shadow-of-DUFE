# IGoLibrary 能力迁移清单

最后更新：2026-07-29

本文档是 IGoLibrary 能力是否保留、如何融入东财之影以及当前实现进度的唯一清单。任何能力不得在没有记录和沟通的情况下删除。

## 产品入口

图书馆不是独立的桌面控制台，而是东财之影“校园服务”的一部分：

- 今日学习台只展示当前/明日预约和需要处理的提醒。
- “我的”页负责连接、授权和个人偏好。
- “图书馆”页负责选座、定时预约、空位发现和预约管理。
- 手机直接使用同一套响应式页面，不维护第二套控制面板。
- 协议、网络、备份和诊断只进入高级设置。

## 已明确禁止的实现方式

以下是实现约束，不等于删除对应产品能力：

- 不伪造 GPS、蓝牙或到馆状态。
- 不做无上限、无范围、无冷却的高频请求。
- 不把 Cookie、授权链接、API 密钥写入前端持久存储或普通日志。
- 不把外部写操作交给 AI 静默执行；必须使用同一动作服务、确认规则和审计记录。

## 本地验收

- 普通启动：`npm run xiaoying:x1`
- 同一 Wi-Fi 手机扫码：`npm run xiaoying:x1:lan`
- 测试：`npm run test:xiaoying`
