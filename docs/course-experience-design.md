# 课程经验与选课建议

## 产品定位

“学长学姐经验”服务于下一位选课者，重点记录课程体验和学习建议，不做教师排行榜，也不把未经核实的个人评价直接公开。

## 展示结构

课程详情页在“学习资料”后显示经验卡片；没有内容时不展示空模块。

- 一句话结论：适合谁、最需要注意什么
- 难度、作业量、节奏：使用低 / 中 / 高三级标签
- 考核方式：考试、论文、展示、平时作业及已知占比
- 先修建议：开始前最好掌握的知识或工具
- 学习建议：按课前、课中、期末三个阶段组织
- 资料建议：指出站内哪类资料最有用，不重复上传文件
- 选课提醒：时间投入、软件要求、分组安排等
- 背景信息：学期、专业/年级、课程班次；不公开学号和真实姓名
- 更新时间：帮助读者判断经验是否仍适用

## 数据模型

```text
course_experience
  id
  course_id
  offering_id?          # 可选，关联具体教师与班次
  semester
  contributor_context   # 例如“会计学院 2024 级”
  summary
  difficulty            # 1–3
  workload              # 1–3
  pace                   # 1–3
  assessment[]
  prerequisites[]
  study_advice[]
  material_advice[]
  selection_notes[]
  status                 # draft / review / published / archived
  reviewed_by
  published_at
  updated_at
```

## 发布流程

第一阶段由站长后台录入：草稿 → 预览 → 发布。第二阶段开放投稿后，学生提交内容只能进入审核箱，不能直接出现在网站。

审核规则：

1. 保留具体、可验证、对学习有帮助的内容。
2. 删除真实姓名、学号、联系方式和可识别个人的信息。
3. 教师相关内容只保留教学安排、考核方式和课堂体验，不发布侮辱、猜测或未经证实的指控。
4. 多条经验可以并存，并用“常见共识 / 个别体验”区分，避免把单一经历写成事实。
5. 内容跨学期失效时归档，不直接覆盖旧记录。

## 后续账号体系

微信登录可用后，投稿人与公开署名分离。网站仅保存必要的内部用户标识；公开端默认显示“已修读学长/学姐 + 专业年级背景”。作者可以撤回自己的投稿，站长保留审核和归档记录。
