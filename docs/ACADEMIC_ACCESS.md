# 东财教务接入核查

2026-09-28，功能已部署到隔离 staging；发布前仍需用用户自己的实验账号完成一次有效登录验收。

## 已确认的官方路径

- 官方教务入口仍由东北财经大学 VPN 验证；登录后的本学期课表路径为 `/student/courseSelect/thisSemesterCurriculum/index`，考试安排路径为 `/student/examinationManagement/examPlan/index`。
- 已在用户登录后的真实课表页确认课程号、课程名、课序号、教师、考试类型、时间与地点字段；真实页面包含多教师、多个 meeting、三节连排以及 `1-9周`、`10-18周`、`2-18周` 等周次。
- 学校 VPN 的密码登录使用动态 RSA 公钥与防重放随机数；服务端按官方页面当前协议加密后提交。无效实验请求已由真实网关稳定返回账号或密码错误，未建立上游事务。

## 当前实现

- 首页和“我的课表”提供“连接教务并导入”，用户不需要下载、复制或上传文件。一次操作同时读取本学期课表与考试安排；学校要求短信验证时在同一弹层继续。
- 短信续验遵循学校当前页面的三种号码语义：单个绑定号码不回传脱敏号码；没有绑定号码时由用户填写本次接收号码；多个号码时由用户选择。本站不绕过学校二次认证。
- 教务账号、密码、验证码与 VPN Cookie 不持久保存。密码只存在于单次请求；短信流程只在服务内存保留五分钟随机事务，成功、失败或超时后丢弃。
- 保存的学期快照保留课程号、课序号、教师、多个上课时段、精确周集合、教室与考试日期/时间/考场/座位。正式教务课程与手工课程分层，手工内容继续保留，正式数据不可被误拖删除。
- 游客快照只保存在当前浏览器；登录用户通过既有个人数据同步保存规范化快照。默认一学期抓一次，只有用户主动刷新才再次访问学校系统。
- 课表或考试页面登录失效、响应异常或结构无法识别时整次失败，不把部分结果写成成功，也不把解析失败显示成“暂无考试”。
