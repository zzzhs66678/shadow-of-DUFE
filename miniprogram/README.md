## 已实现

0.2.0 以下能力已完成本地实现并通过59项测试、13页检查；尚未上传新体验版。

- 网站账号：通过本站HTTPS专用接口使用已有账号或邮箱、密码登录；账号UUID与网站一致，不按微信昵称或momo合并账号。注册与找回密码提供官网地址入口，未在小程序内实现对应表单。
- 网站内容：只读查看全部已保存课表方案、教务课表、日程、作业与已有考试安排。首次登录不上传本机内容；明确切换网站/本机来源，本机课表与作业独立保留。退出、过期或切账号清除私人预览，迟到响应不会恢复旧账号内容。
- 官网式首页：日期、学期、校园时间、公开校园入口、标题旁课程检索入口、最近考试、下一节课、最近作业与今日时间线按实际数据展示。课程时段和考试使用真实字段，未确认或过期考试有提示，不推算考场、座位或考号。
- 官网式课表：横向切换教务与手动方案，选择学期和教学周，默认五天并保留有课周末，可显示完整七天或按日查看。课程、地点、教师、有效周分层显示；按实际节次提示冲突并保留跨大节时段，网站教务记录支持到30周、14节。方案和周选择仅查询，不修改网站当前方案。
- 微信绑定候选：先通过微信验证取得服务器身份，再登录已有网站账号，明确确认账号并再次验证网站密码后绑定其UUID；不自动创建新账号。挑战绑定原会话、单次使用，退出/切号/过期后失效。客户端只按服务端能力开关显示入口，当前密钥未配置，入口关闭；真实微信流程尚未验收。

0.1.0已上传的本机工具能力保留如下；0.2.0继续使用这些基础，不意味着网站端编辑已接入。

- 今日课程：以北京时间显示日期；手动教学周有明确说明，设置开学日期后可自动计算。
- 课程查询：按课程名、课程号、教师、班级检索；与官网同样支持“近代史”“高财”“高数”等简称和多词排序，区分上下学期，分页展示。简称规则不参与课程或教学班身份判断。
- 教学班详情：按稳定 `sectionId` 组织所有上课时段，显示教师、主修班级、有效周、实际节次、地点和教材。
- 本机个人课表：默认周一至周五整周网格，自动显示有课周末；保留按日管理。加入教学班全部时段；按实际周和节次提示冲突，用户确认后可保留；移除也是整个教学班。网站只读模式按网站实际meeting选择展示，不扩成整个教学班。
- 班级导入：必须明确选择完整班级名并确认，只合并该班实际教学班；不按专业猜测个人选课。
- 空教室：按学期、教学周、星期、大节、楼查询已知排课；可查看教室一周排课，并按原meeting ID定位课程详情与原教学班，失效时不猜替代。只展示来源数据出现过的房间，不声称实时空闲或开放。
- 日程与作业：本机增改删、作业完成/恢复、课程关联、单次与有明确结束日期的每周日程；有效日期和时间校验，未保存修改与删除确认，首页显示当日日程和近期作业。最多300项，保存失败不显示成功。
- 我的：教学班/作业/日程统计与管理入口。校园入口只复制相应公开网址，不读用户剪贴板，不代传学校会话；用浏览器打开。
- 设置、项目说明和隐私说明；本机持久保存、损坏存储报错和主动清除。

## 导入微信开发者工具

需要Node.js 22.13+和可读取已发布提交的Git仓库，使用网站仓库已有工具即可。本子项目没有运行时依赖，无须单独`npm install`。测试、导航图标再生成和浏览器布局检查使用网站根目录已有的TypeScript、sharp、Playwright依赖。

在仓库根目录执行：

```powershell
npm --prefix miniprogram run build
npm --prefix miniprogram test
npm --prefix miniprogram run check
```

在微信开发者工具选择「导入项目」，目录选本文件所在的 **`miniprogram` 文件夹**。
`project.config.json`中的`miniprogramRoot`已指向生成的`dist/`，AppID已按后台「基本设置 → 账号信息」核对为`wx1cb3e08b6adc0fcd`。
使用管理员或已加入项目成员的开发者微信登录后，可检查模拟器并上传体验版。
本机已安装腾讯官方微信开发者工具`2.02.2609231 RC`，项目已导入、编译和上传成功。AppID可以进客户端；**AppSecret、私钥、网站Cookie、验证码不能放进客户端或仓库**。

源文件在 `src/`，构建会复制源码并从记录的已发布Git提交生成字典压缩数据。
请修改源文件后重新构建，不要编辑 `dist/`。构建会检查保守的2,000,000字节主包预算；实际大小以本次构建输出为准。
更新课程数据后重新构建，已选教学班按原标识保留；无法匹配的选择会在课表页提示，不会悄悄删除。

## 数据、登录和网络

当前数据来自上述已发布网站提交的公开课程目录：1,759门课程、5,870个时段。
来源表的「上学期 / 下学期」不自动对应某一学年，数据生成日期在项目说明页展示。
随包公开课程按原有效周集合展示，本机工具的教学周查询范围为18周；网站教务快照按其实际周次支持到30周，不补猜未知周次。本机未设置开学日期时默认手动第1周并明确提示。网站学期起始日期沿用锁定发布版本的设置，不将其当作学校确认的最新校历。

已上传0.1.0不调用网络或微信登录，公开目录随代码打包，本机课表、学期设置、日程和作业保存在微信本地存储。

0.2.0候选通过 `wx.request` 访问固定的 `https://dufesh.cn` 原生账号与公开课程目录接口。网站密码仅用于本站HTTPS登录或绑定确认，不保存到本机；保存短期、可撤销的原生会话，最长24小时。公共目录请求不附私人账号令牌，私人快照只在内存中查看，接口响应禁止缓存。原生Bearer与网站Cookie用途分离，保留网站Origin保护，不把凭据放进URL。

**网站内容目前只读。本机编辑不会写到网站，网站内容也不会覆盖原有本机记录；换设备只能重新登录读取网站已保存内容。** 网站快照的未适配字段完整保留于读取结果，但培养方案等尚无原生展示或编辑页面。

微信候选流程仅在服务端能力确认可用后调用 `wx.login`；当前服务密钥未配置，登录和绑定入口关闭。AppSecret只允许放在服务器配置，不进客户端、仓库或日志。网页OAuth审核与Cookie会话不能直接作为小程序微信登录。本轮不调用定位、手机号、支付或学校认证接口，不收学校密码，也不将微信登录当作东财学生认证。
